## Lab1 任务

1. 编译并运行原始内核，区分 OpenSBI 信息与内核自己的输出。
2. 阅读入口汇编、C 初始化、链接脚本、构建文件和输出模块，说明整体执行流程。
3. 完成练习一，解释入口处设置栈指针与跳转到 C 入口的指令作用和目的。
4. 完成练习二，使用 GDB 观察从复位到第一条内核指令的过程，保存调试证据并解释最初几条指令。
5. 完成报告中的原理联系、未覆盖知识点和问题分析；推送材料并准备每位成员的现场问答。

Lab1 无需额外新增内核功能。GDB 调试是实验任务，AI 操作 GDB 不是已明确的必选方式。使用 AI 时保存真实交互与验证记录；Lab1 的具体 AI 提交格式向助教确认。

## 环境与验证边界

课程材料与课堂讲解采用 RISC-V GCC 10.2.0、QEMU 4.1.1 等工具。请在报告中记录实际使用的系统、工具版本、执行方式与结果。工具链和 QEMU 安装在仓库外，不随代码提交。

当前压缩包未包含 `tools/grade.sh`，尽管 Makefile 引用了它；暂不把该评分目标当作可用验收方式。实际运行与调试结果应据实记录，不预填成功结论。
